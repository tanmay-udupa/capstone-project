Agent-hours are the sum of job durations across every job in a run, including jobs that run at the same time. Only completed runs are included. Agentless jobs such as approvals or waits are counted too, so check the lists above for them before quoting totals. A failure counts as late when the run lasted 30+ minutes and at least half as long as the pipeline's median passing run. Failed runs whose commit later passed on the same pipeline are shown separately, as likely flaky.
